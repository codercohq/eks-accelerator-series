# EP9 diagrams

Editable source for the Episode 9 diagram. Open `ep9-ingress.drawio` in [draw.io](https://app.diagrams.net) and export to PNG or SVG for slides.

One page, the ingress flow: a user to the NLB to Traefik to the services, with the two routing rules shown on the arrows.

Colour key: blue is the user, orange is the layer-4 NLB, green is Traefik and the services it routes to.

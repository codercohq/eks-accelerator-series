# EP9 diagrams

Editable source for the Episode 9 diagram. Open `ep9-workloads.drawio` in [draw.io](https://app.diagrams.net) and export to PNG or SVG for slides.

One page, the Kustomize shape: one base, a dev overlay and a prod overlay, with the HPA scaling prod.

Colour key: blue is the shared base, green is the environment overlays, orange is the autoscaler.
